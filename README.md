# A&J CAPITAL — primera versión web

Incluye:
- Login con Supabase Auth
- Dashboard responsive
- Capital prestado
- Intereses del ciclo
- Cartera vencida
- Resultado 20→20
- Participación provisional Andrés/Juan
- Tabla de cartera con semáforo

## Antes de publicar
1. Ejecutar `SEGURIDAD_SUPABASE.sql` en Supabase.
2. En Supabase > Authentication > Users, crear los dos usuarios: Andrés y Juan.
3. Probar el inicio de sesión localmente o en GitHub Pages.
4. No usar ni publicar una service_role key. La app usa solamente la publishable key.

Los demás módulos del menú quedan preparados visualmente para conectarlos en el siguiente bloque.
